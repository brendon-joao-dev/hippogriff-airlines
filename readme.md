## 📖 Sobre o projeto

Este projeto foi desenvolvido para praticar conceitos de Python orientado a objetos e sua integração com bancos de dados SQLite.

## ✨ Funcionalidades

- [X] CRUD de viajantes
- [X] CRUD de companhias aéreas 
- [X] CRUD de aviões
- [X] CRUD de rotas
- [X] CRUD de passagens
- [X] Exibição de menus e submenus no terminal
- [X] Sistema que se mantém rodando até o usuário encerrar a sessão
- [X] Leitura de dados do banco de dados
- [X] Validações das estradas do usuário

## 🛠️ Tecnologias utilizadas

| Camada | Tecnologia |
|---|---|
| Front-end | Python no terminal |
| Back-end | Python Orientado a Objetos|
| Banco de dados | SQLite |
| Outras ferramentas | Git para versionamento |

## 📂 Estrutura do projeto

```
📁 back_end/      → Lógica de processamento e interação com banco de dados
📁 banco_dados/   → Estrutura do banco de dados
📁 front_end/     → Lógica pra desenhar "telas"
📄 .gitignore     → Ignora os pycache
📄 main.py        → Arquivo de execução do projeto
📄 teste.py       → Arquivo usado pra testes
📄 validacoes.py  → Testes de construção de validações
```

## ▶️ Como executar o projeto

### Pré-requisitos
- Python instalado na versão 3 ou mais

### Passo a passo

```bash
# clone o repositório
git clone https://github.com/brendon-joao-dev/hippogriff_airlines.git

# entre na pasta do projeto
cd hippogriff_airlines

# execute o projeto
python main.py
```
